# M1 阶段验收记录（2026-09-19）

## 结论与范围

用户在真实耳机麦克风下完成商家问候、身份、服务/价格查询、价格异议、预约意向、受控推荐和多次插话测试后，明确接受 M0/M1。本次只验收“网页实时中文语音底座 + 一条真实只读商家 HTTP 工具接缝”，不代表完整预约产品通过，也不进入 M2。

状态只使用：**通过、失败、阻塞、未执行**。自动化、真实模型/工具和真人麦克风证据不互相替代。没有证据的项目保持未执行。

## 环境与冻结版本

- Windows，Node.js 24.15.0，npm 11.12.1，Python 3.12 项目虚拟环境。
- Qwen Audio Agent 1.11.0，锁定提交依据见 `docs/upstream/QWEN_AUDIO_AGENT.md`。
- PostgreSQL 17.11 Alpine，镜像以 `compose.yaml` 中 digest 锁定。
- 千问真实 Realtime、真实本地 FastAPI 工具、真实 PostgreSQL、真实 Chrome 和真实 USB 音频输入。
- 语音轮次配置：原生 `server_vad`，`threshold=0.65`，`silence_duration_ms=1800`。
- 录音输入全局配置：`VOICE_AUDIO_INPUT_LABEL=USB Audio Device`；实际轨道回报 `麦克风 (USB Audio Device)`。指定设备不存在时禁止静默回退。
