# Codex 实施计划

状态：以各任务的“当前状态”和文末进度为准；当前已完成 M4 实现、独立 Review 局部修复与 A/B 层复验，停在真人语音阶段验收前，不自动进入 M5。此文件中的证据链接指向实际执行记录。

## 工作原则
每次执行一个有明确验收结果的任务。任务可以跨前后端少量文件，但不能混入其他不相关能力。
不要按“先所有后端，再所有前端，最后才接语音”推进。先消除语音接缝风险，再持续跑小闭环。
先用美容贯通一条预约，再扩展医院和日托；不因此取消另外两类的交付范围。
模块完成 != 接入完成 != 真实语音验收通过。每项分别报告。

任务状态只使用：未开始、进行中、代码完成待验证、自动测试通过待真人验收、已验收、阻塞。
新发现的问题要记录阻塞对象，不把所有开发无条件停下，也不越过关键依赖假装完成。
各阶段结束更新本文件，记录实际 commit、测试命令、证据路径和下一项；不要生成百分比完成率。
